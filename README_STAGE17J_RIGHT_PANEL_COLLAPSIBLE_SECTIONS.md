## What this adds

A layout-only organizer for the Copilot and Settings tabs.

Groups:

- Paper AI
- Citations
- History / Comments
- Presentation
- Figures
- Reports / Reviews
- AI / Model configuration
- Diagnostics

Controls:

- Expand all
- Collapse all
- Refresh sections
- Copy report

The expanded/collapsed state is remembered in local storage.

No AI calls and no compile jobs.
