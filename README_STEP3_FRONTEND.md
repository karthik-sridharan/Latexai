# Latexai Step 3 GitHub Sync Frontend

Upload/replace these files in your GitHub Pages repo:

- `index.html`
- `js/lai-storage-provider-preload.js`
- `js/lai-storage-ui.js`
- `js/lai-github-sync-ui.js`

Open:

https://karthik-sridharan.github.io/Latexai/?v=stage3-github-sync-1

You should see two floating panels:

- Latexai Storage, bottom-right
- GitHub Sync, bottom-left

The GitHub panel needs the backend service deployed and a GitHub token configured on that backend.
