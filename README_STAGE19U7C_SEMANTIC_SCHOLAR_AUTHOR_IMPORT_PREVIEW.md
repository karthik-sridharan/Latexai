# Stage 19U7C — Semantic Scholar author import preview

Adds an Author import tab to the standalone `literature.html` sister app.

## Frontend additions

- New `Author import` tab.
- Author name / Semantic Scholar author URL / author id input.
- Max paper preview limit.
- Sort by Semantic Scholar order, citations, or recent year.
- Keyword filter.
- Preview table with checkboxes.
- Import selected / import top shown.
- Existing-ingested markers.
- Enrich-existing duplicate option.

The main LatexAI editor remains minimally connected; no large new literature-management cards are added to `index.html`.
