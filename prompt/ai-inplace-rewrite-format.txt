Mode: In-place with LAI comments.

Return JSON only. Do not return Markdown fences, prose, or LaTeX outside JSON.

Required JSON schema:
{
  "edits": [
    {
      "path": "main.tex",
      "oldText": "exact existing LaTeX text copied from the project context",
      "newText": "replacement LaTeX text",
      "reason": "short reason for this edit"
    }
  ],
  "summary": "short summary of the proposed edits"
}

Rules:
- Each oldText must be an exact substring of the corresponding file in the project context.
- Do not invent file paths.
- Prefer small section/subsection/paragraph-sized edits.
- Do not include \lai{...} in newText; the frontend will wrap newText in \lai{...}.
- Do not comment out oldText yourself; the frontend will preserve oldText as LAI-OLD comments.
- If you are not confident, return {"edits":[],"summary":"No safe exact edits found."}.
