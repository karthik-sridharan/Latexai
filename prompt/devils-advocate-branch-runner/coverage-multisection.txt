Coverage rule for the final editor step:
- For EVERY requested target section/unit, output AT LEAST ONE visible coverage/edit block.
- If edits are needed for a target, output one or more substantively distinct PATCH-STYLE blocks for that target; normally no more than two non-overlapping blocks per target.
- If no edits are needed for a target, output exactly one no-edit block for that target; do not also output edits for that target.
- Use the exact target section/unit names listed above so the insertion step can distribute blocks correctly.

Patch-style block requirements:
- DO NOT output review/advice prose such as "Add a paragraph...", "Insert after...", "Replace the current paragraph with...", or "Consider citing..." inside \lai.
- Instead, output the actual LaTeX-ready text to insert, or a true replacement pair using \laiold{old text}\lai{new text}.
- Put the target label as a LaTeX comment inside the block, not as visible paper text.

}

No-edit block format:
\lai{%
% Target section: <exact section title>
\emph{No edits recommended.}
}
