Fixes covered
-------------
- Competitive review reports that include patch blocks inside Markdown no longer send the full report as source-edit input.
- Malformed patch blocks that omit END_NEW_LATEX can still be recovered if the block boundary is clear.
- Accidental terminal \end{document} inside a malformed patch payload is stripped as a boundary artifact.
- Safe compiler validation no longer blocks all future edits merely because the original user source already contains old scaffolding/Markdown from previous runs.
- Section-level replace requests without safe block ids no longer fail closed; they become visible section-level \lai suggestions.
- append_before_end_document is preserved as its own semantic operation instead of being collapsed into legacy append_review_note naming.
- Repair prompts now demand patch-only output, no Markdown report, no code fences, and no document/preamble commands inside BEGIN_NEW_LATEX.
