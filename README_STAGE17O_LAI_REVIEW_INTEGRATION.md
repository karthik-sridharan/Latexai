# Stage 17O — `\lai` review integration for Devil’s Advocate and Competitive Review

Stage string: `stage17o-lai-review-integration-for-devils-competitive-1`

This stage connects the actionable `\lai` / `\laiold` edits generated by Devil’s Advocate and Competitive Review back into the existing Paper-level edit review workflow.

## What changed

- Competitive Review and Devil’s Advocate still save full reports under `/reviews`.
- Their insertion buttons now insert visible LaTeX AI markup, not comment-only roadmaps.
- Inserted blocks carry lightweight source metadata in surrounding marker comments, for example:

```latex
% BEGIN LAI-ACTIONABLE-EDIT id=lai-competitive-abc workflow=competitive-review path=main.tex mode=replace
% LAI target: introduction positioning paragraph
\laiold{
old source text
}
\lai{
new suggested text
}
% END LAI-ACTIONABLE-EDIT id=lai-competitive-abc
```

- The Paper-level edit review panel can now scan project-level `\lai` edits, not just the active file.
- Paper-level edit rows show the originating workflow, such as **Competitive Review** or **Devil’s Advocate**.
- After inserting inline edits or appending a `\lai` plan, Latexai automatically refreshes the Paper-level edit review queue.
- Revision history now snapshots before both inline insertions and append-plan insertions.

## User-facing result

After running Devil’s Advocate or Competitive Review:

1. Click **Insert `\lai` edits at matches** or **Append `\lai` plan**.
2. The Paper-level edit review panel refreshes automatically.
3. The user can review, accept, or reject the inserted changes using the existing Paper-level edit review controls.

## Guardrails

- Inline insertion still requires exact source matching.
- If exact matching fails, the user can append the high-level improvement plan as a `\lai{...}` block before `\end{document}`.
- No workflow inserts the old comment-only roadmap as the primary path.
