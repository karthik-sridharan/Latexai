# Stage 19U4 — Hybrid literature retrieval ranking frontend

Surfaces hybrid retrieval diagnostics in all knowledge preview cards.

The retrieved-paper cards now show:

- hybrid score,
- semantic score,
- score breakdown,
- why the paper was retrieved,
- pinned boost when a paper is manually pinned.

The prompt context sent to AI agents also includes the evidence-audit fields so reviewers can cite which retrieved papers influenced their analysis.
