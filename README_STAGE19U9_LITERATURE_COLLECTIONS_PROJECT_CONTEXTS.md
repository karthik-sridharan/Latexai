# Stage 19U9 — Literature collections and project contexts

Adds named literature collections to the standalone `literature.html` sister app and lets the main LatexAI knowledge-context controls consume a selected collection as project context. Collections are thematic reading lists with paper roles such as `central`, `background`, `competitor`, `methodological`, `maybe`, and `excluded`.

The main editor remains minimal: only the existing knowledge-context controls are extended with a collection selector and collection-aware retrieval modes.
