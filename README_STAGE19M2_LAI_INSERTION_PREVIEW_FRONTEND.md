# Stage 19M2 — Cleaned LAI Edit Preview + Insert/Append Workflow Frontend

Updates `developer-debate-branches.html` with a developer workflow for Stage 19M2.

New controls:

- Preview insert/append cleaned LAI
- Copy targeted draft
- Copy append draft
- Use targeted/append draft as the page's LaTeX source excerpt for inspection
- Record applied/rejected outcome back to memory feedback

This does not silently modify the main Latexai editor. It previews drafts and records user feedback for the memory-policy loop.
