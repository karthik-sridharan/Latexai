Settings

            
Backend URLs and compile settings

          

        

        
Stage 19C2 keeps AI generation, memory storage, compile routing, and GitHub sync as separate services. Backend/API settings are preserved when creating a new project.

        
        
        
        
        

          

            
Memory backend status

            Not checked
            
Use Test memory backend after setting the Neon-backed memory URL. This writes one harmless diagnostics scope so you can verify memory from an iPad without browser console.

          

          
        

        
        
The GitHub backend is separate from AI, memory, and compile. It is used only for project open/save, GitHub-backed New Project, and project version history.

        

          

            
GitHub backend status

            Not checked
            
Used by Project → Open Project / Save Project. Test GitHub backend only confirms the sync service URL/token; repository loading still requires the exact owner/repo, branch, folder path, and token access.

Backend status

            Not checked
            
Use Test backend after setting the compile endpoint. The status and jobs endpoints are derived from the same backend URL.

          

          
        

        
        
        
        
        

          Direct backend compile is the default. If job-based compile is enabled, Lumina derives /api/lumina/latex/compile/jobs and /api/lumina/latex/status from the compile endpoint so stale backend URLs do not linger.
        

        

          Active backend routes: POST /api/lumina/latex/compile, optional POST /api/lumina/latex/compile/jobs, GET /api/lumina/latex/compile/jobs/:jobId, and GET /api/lumina/latex/status.
